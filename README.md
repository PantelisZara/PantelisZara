## Featured Projects

### 🔹 Warexis

Event-driven order, inventory and fulfillment platform with three Java 21/Spring Boot services communicating through Kafka. Transactional outboxes, idempotent consumers, bounded retries and dead-letter handling make delivery guarantees explicit.

Includes PostgreSQL, Keycloak OAuth2/OIDC, React/TypeScript, automated integration and browser tests, GitHub Actions, and optional Prometheus/Grafana/Tempo observability. Runs locally with Docker Compose or single-node Kubernetes using kind.

➡️ [Explore Warexis](https://github.com/PantelisZara/Warexis)

---

### 🔹 Issunexa

Support-ticket management modular monolith built with Java 21, Spring Boot, PostgreSQL and React/TypeScript. Demonstrates requester/staff authorization, session authentication with CSRF protection, optimistic locking, comments and workflow history within local database transactions.

Includes Docker and automated backend, frontend and browser verification.

➡️ [Explore Issunexa](https://github.com/PantelisZara/Issunexa)
