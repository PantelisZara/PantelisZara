# Pantelis Zarakis

Computer & Telecommunications Engineering student at International Hellenic University. I build Java backends and React interfaces, with a focus on reliable data flows, application security and automated testing. My current work explores distributed messaging, local Kubernetes deployments and CI.

## Featured engineering projects

### [Warexis](https://github.com/PantelisZara/Warexis)

An event-driven order, inventory and fulfillment platform with three Spring Boot services communicating through Kafka. Transactional outboxes, idempotent consumers, bounded retries and dead-letter handling make delivery guarantees explicit.

Includes Keycloak OAuth2/OIDC, a React/TypeScript workspace, integration and browser tests, GitHub Actions, and optional Prometheus/Grafana/Tempo observability. Runs locally with Docker Compose or single-node Kubernetes using kind.

### [Issunexa](https://github.com/PantelisZara/Issunexa)

A modular monolith for support-ticket management, built with Spring Boot, PostgreSQL and React/TypeScript. Requester/staff authorization, session authentication with CSRF protection, optimistic locking, comments and workflow history keep the ticket lifecycle explicit within local database transactions.

Includes a Docker setup and automated backend, frontend and browser verification.
